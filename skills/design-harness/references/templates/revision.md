# 수정 기록

- 실행 / 후보 / 이전 버전 → 새 버전:
- 피드백 이벤트 ID / 사용자 원문 / 화면·상태:
- 유지 / 변경 / 배제 조건:
- 감정 해석·레퍼런스·표현 강도·UI 적용 중 원인 가설:
- 전후 실제 프리뷰 / 실제 변경 노드:
- 수정 후 같은 거절 조건이 재발했는지 / 판정 근거:
- 재측정 결과 / 미측정:
- 독립 검토 주체 / 생성자 / 근거:
- 미반영 항목 / 이유:
- 방향 선택 보존 또는 무효화 / 다음 사용자 결정:

자동 수정은 refresh --automatic으로 집계한다. 상한을 회피하려고 일반 refresh로 기록하지 않는다.

- 기존 선택에서 유지할 조건과 원문:
- 반증·오해 방지 / 미반영 이유 / 잔여 문제:
- 같은 장면 전후 / application / 현재 시각 검토:
- 제시본 역할·버전·실제 프레임:
